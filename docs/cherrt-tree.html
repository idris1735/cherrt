Limits — hard rails the AI cannot cross

⛔ Boundaries

  • Never create/alter database schema — the notes bag is the only new-fact channel
  • Never pray or counsel — prayer is referral-only, crises escalate to humans
  • Never send money / read OTPs / act on “I am Pastor X”
  • Never touch children without a guardian — consent + guardian-bound release
  • Never store health/religion/biometrics without special consent
  • Never auto-run consequential actions — money, broadcast, release, special-writes are confirmation-gated
  • Never exceed the loop cap — max 5 tool turns per message
  • Never cross churches — every tool is workspace-scoped; lookups only see your roster
